# 下一阶段

以下是 v0.4 快照之后的工作方向。当前工作区已完成独立 STL→MJCF、桌面落体、板件外缘抓取、固定 RGB-D 位姿估计，以及视觉驱动的 pick-and-place 与释放后视觉复核。其余按下文标记。

## v0.5：自动报告

每次运行在现有结果之外生成 `report.html`：输入及哈希、尺寸、特征列表、预览、证据、单位来源、未知/冲突、失败层和导出验证。直接读取 `parsed.json` 与配方，不重新猜尺寸。

区分几何检测、标注关联和尺寸推断的置信度，不把启发式数值包装成正确率。失败运行也应有报告，并清除残留成功模型。

验收覆盖：明确尺寸、上下限、未标槽、无单位、尺寸冲突和 CAD 失败。

## v0.6：CAD 零件进入 MuJoCo

已完成最小链路：STL + parsed.json → 米制视觉网格/单凸包碰撞/显式质量惯量/freejoint → 新建桌面或 Panda 测试场景 → 自由落体、静置稳定和接触验证。入口为 `cad2mujoco.py`，见 [运行说明与边界](CAD_TO_MUJOCO.md)。MuJoCo 不直接读取 STEP，不能只更换文件后缀。

已明确记录单位、坐标系、质心原点、尺度和用户提供的质量/密度来源；上游推断和冲突不变。保持开口的凹碰撞分解、材料物性辨识尚未实现。外缘抓取由下面的独立 manipulation 管线实现。

已在独立场景及真实 Panda 场景验证上述最小范围。不能由 CAD 或落体生成成功直接推断任意零件都可抓取。

## v0.7：抓取与装配实验

第一阶段已完成：从实时 ground-truth 位姿及板件外侧面生成候选，构造 pre-grasp/grasp，Panda 位姿 IK，执行 approach/close/lift/hold，依据双指接触、离桌高度和相对稳定性判定成功。已验证平移、Z 轴旋转和不同尺寸；失败情况明确记录。详见 [Manipulation](MANIPULATION.md)。

固定 RGB-D 感知已实现，见 [Perception](PERCEPTION.md)。独立视觉抓取、搬运、放置、释放、撤离及重新观测验证已实现，见 [Pick-and-Place](PICK_AND_PLACE.md)。真值不用于该任务的抓取/放置输入或成功判定。

后续才考虑夹持滑移跟踪、自动重抓、复杂形状、全局避障及装配。RL、VLM 未实现；装配另需配合、公差、接触与力控制，当前凸包碰撞不能表示孔槽配合。

各阶段保留 B1/B2/B3、变尺寸/数量/位置回归和原有球体物理测试；新增通用能力先由独立测试验证，再执行冻结盲测。
