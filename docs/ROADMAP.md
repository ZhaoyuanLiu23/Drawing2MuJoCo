# 下一阶段

以下功能尚未实现，不属于 v0.4 已交付能力。

## v0.5：自动报告

每次运行在现有结果之外生成 `report.html`：输入及哈希、尺寸、特征列表、预览、证据、单位来源、未知/冲突、失败层和导出验证。直接读取 `parsed.json` 与配方，不重新猜尺寸。

区分几何检测、标注关联和尺寸推断的置信度，不把启发式数值包装成正确率。失败运行也应有报告，并清除残留成功模型。

验收覆盖：明确尺寸、上下限、未标槽、无单位、尺寸冲突和 CAD 失败。

## v0.6：CAD 零件进入 MuJoCo

规划链路：参数化实体 → 三角网格 → 视觉网格/碰撞表示 → MJCF 资产与 body → 物理验证。MuJoCo 不直接读取 STEP，不能只更换文件后缀。

明确处理 mm→m、坐标系、原点、网格尺度、质量/密度/惯量、碰撞分解和接触参数。图纸没有给出的材料与物性由用户参数提供，并记录来源。

先验证自由落体、静置稳定性、碰撞范围和惯量，再接入 Panda。不能由 CAD 生成成功直接推断任意零件都可抓取。

## v0.7：抓取与装配实验

建立候选抓取位姿、可达性、碰撞、稳定夹持和释放检查。装配另需配合、公差、接触与力控制。

各阶段保留 B1/B2/B3、变尺寸/数量/位置回归和原有球体物理测试；新增通用能力先由独立测试验证，再执行冻结盲测。
